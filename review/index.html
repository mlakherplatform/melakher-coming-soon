طريقة الاستخدام

  1. راجع العنصر الحالي وعدّل أي قيمة تحتاج إلى تصحيح.
  2. في حالة وجود Array يمكنك إضافة أو حذف العناصر وتعديل قيمها مباشرة.
  3. اختر صحيح أو خطأ واكتب ملاحظات المراجعة إن وجدت.
  4. اضغط حفظ وانتقال للتالي لحفظ التعديلات والمراجعة والانتقال تلقائيًا للعنصر التالي.
  5. استخدم تصدير المراجعة للاحتفاظ بالداتا مع سجل المراجعة.
  6. استخدم تصدير البيانات النهائية للحصول على البيانات بدون حقول المراجعة، لتكون جاهزة للإدخال في قاعدة البيانات.
  7. استخدم استيراد بيانات لإضافة Dataset جديد بصيغة JSON أو JavaScript بدون حذف البيانات الموجودة.
  8. عند استيراد Dataset جديد، يتم منع التكرار تلقائيًا باستخدام slug.

مهم: البيانات المحفوظة في localStorage مرتبطة بهذا المتصفح والجهاز. يُفضل عمل تصدير دوري كنسخة احتياطية.
