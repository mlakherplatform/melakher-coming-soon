قرار المراجعة

طريقة الاستخدام

  1. راجع العنصر الحالي وعدّل أي قيمة تحتاج إلى تصحيح.
  2. اختر صحيح أو خطأ واكتب ملاحظات المراجعة إن وجدت.
  3. اضغط حفظ وانتقال للتالي لحفظ التعديلات والمراجعة والانتقال تلقائيًا للعنصر التالي.
  4. استخدم تصدير بيانات المراجعة للاحتفاظ بالبيانات مع سجل المراجعة.
  5. استخدم تصدير البيانات النهائية للحصول على البيانات بدون حقول المراجعة.
  6. استخدم استيراد البيانات لإضافة بيانات جديدة بدون حذف البيانات الموجودة.
  7. عند استيراد بيانات جديدة، يتم منع التكرار تلقائيًا باستخدام المعرّف.
  8. يمكنك استخدام إعادة ضبط البيانات لحذف البيانات المحفوظة محليًا والرجوع إلى البيانات الأصلية.

مهم: البيانات المحفوظة مرتبطة بهذا المتصفح والجهاز. يُفضل عمل تصدير دوري كنسخة احتياطية.
